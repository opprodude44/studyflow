# StudyFlow

A study planner that plans for you. Static website (GitHub Pages) + Supabase for accounts and saving.

- `index.html`: the app
- `config.js`: Supabase project address and public key (safe to publish), feature switches
- `auth.js`, `feeds.js`, `ai-shim.js`: sign-in and cloud save, linked calendars, AI bridge (AI is off for now)
